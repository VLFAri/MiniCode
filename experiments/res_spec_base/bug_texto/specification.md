# Specification

## Objective
O objetivo deste projeto é implementar duas funções em Python: `eh_palindromo` e `contar_vogais`, que funcionem conforme as especificações fornecidas.

## Parameters / Requirements
### Função `eh_palindromo`
- Recebe uma string como entrada.
- Ignora maiúsculas, espaços e pontuação.
- Verifica se a string é palíndromo.
- Retorna `True` se for palíndromo, `False` caso contrário.

### Função `contar_vogais`
- Recebe uma string como entrada.
- Conta e retorna a quantidade de vogais presentes na string.
- Considera vogais maiúsculas e acentuadas.

## Acceptance Criteria
1. A função `eh_palindromo` deve retornar `True` para "Anotaram a data da maratona".
2. A função `contar_vogais` deve retornar 7 para "Anotaram a data da maratona".

## Arquivos do projeto
- texto.py

Pedido do utilizador: Em texto.py, eh_palindromo deve ignorar maiúsculas, espaços e pontuação ("Anotaram a data da maratona" é palíndromo) e contar_vogais deve contar também vogais maiúsculas e acentuadas (á é í ó ú â ê ô ã õ). As duas funções estão erradas; corrija-as.
